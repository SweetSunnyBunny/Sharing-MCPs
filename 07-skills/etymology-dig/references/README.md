# etymology-dig chapters

One chapter per language family, plus the shared ledger rules.

- `ledger.md`: the source line, status words, and the dead-ends ledger (the ledger itself lives outside the skill folder, for example `notes/dead-ends.md`)
- `latin-greek.md`: classical Latin and Greek
- `old-irish.md`: Old and Middle Irish
- `biblical.md`: Hebrew and New Testament Greek

When you add a chapter, add its row to the table in SKILL.md at the same time, and only once the file is really on disk.
