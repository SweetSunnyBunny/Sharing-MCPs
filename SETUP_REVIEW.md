# Sharing snapshot review

Snapshot date: 2026-10-19. Covers 37 package folders, documentation and public helpers.

Maintained Anam, cloud services, machine tools, Photos, audio and four added local
adapters were compared with their source implementations. Generic public defaults
intentionally differ from private deployment state. Retained standalone packages
are not represented as newly upgraded third-party projects.

Private prompts, conversations, personal identities, account/voice IDs, contact
numbers, private home art/stories, credentials, databases, logs, caches, compiled
applications and Git history are excluded. The final tree is scanned against
known personal patterns and exact private configuration/voice values. These
checks do not guarantee arbitrary future prose is safe.

The UI has no personal schedule seeds, automatic household actions or configured
SMS recipients. Account-dependent services need the installer's own setup.
Eight tests are skipped for unbundled workstation supervision, private archive
migration and live Photos integration.

Commons includes two newly illustrated public home spaces and 39 retained adventure
areas with approved game artwork. Its 63 isolated tests and browser checks passed.

See [REFRESH_REPORT.md](REFRESH_REPORT.md) for coverage, counts and limitations.
[SETUP_MANIFEST.json](SETUP_MANIFEST.json) records file hashes. A changed file or
added runtime artifact makes [verification](scripts/verify_setups.py) fail.
Clean archives include only manifest-listed files and the manifest itself.
Existing repository history is outside this review.
